# Cenários AWS

Cada adaptação possui uma pasta própria. O primeiro cenário é cloud_breach_s3_academy. Adicione novos cenários somente após documentar e testar suas dependências e limitações.

A preparação de todos os cenários originais e a ordem sugerida estão em [docs/scenarios/aws](../../docs/scenarios/aws/README.md). Essas fichas não devem ser confundidas com adaptações prontas.
